# MIMIC SLOTS — Claude Code 引き継ぎメモ

## ファイル構成
- `CLAUDE.md` — Claude Codeが自動で読む標準指示(素材の自律取得・進め方のルール)。**最優先で読まれる想定**
- `PROJECT_BRIEF.md` — これまでの全チャットの経緯を漏れなくまとめた完全版ブリーフィング
- `index.html` — ページ骨格(構造のみ)
- `style.css` — 全スタイル
- `sprites_data.js` — 画像素材(base64埋め込み、`const SPR = {...}`)
- `audio_data.js` — 音源(base64埋め込み、`const AUDIO_SRC = {...}`)、およびテーマ/絵柄/実績まわりの各種データ定義
- `game.js` — ゲームロジック本体
- `guide_template.html` — 攻略本の手書きソース(文章・レイアウト)。データ部分は`/*BUILD:...*/`プレースホルダー
- `complete_guide.html` — `scripts/build_guide.js`が生成する攻略本の完成版(直接編集しない。公開アーティファクトへのpublish元)
- `secretguide_data.js` — `complete_guide.html`を文字列化したもの(同じくビルド生成物、直接編集しない)。ゲーム内では合言葉入力時に遅延読み込みされる
- `scripts/build_guide.js` — `audio_data.js`/`game.js`の実データから上記2つの攻略本ファイルを再生成するビルドスクリプト。**数値を変更したら必ず`node scripts/build_guide.js`を実行すること**
- `tests/regression.js` — 自動回帰テスト(下記参照)
- `package.json` — `tests/regression.js`実行用。ゲーム自体はビルド不要な静的サイトのまま

ローカルでは `index.html` をブラウザで直接開くか、簡易サーバー(`python3 -m http.server`)経由で開いてください。file://直接開きでも動作確認済みです。

```
npx playwright install chromium # 初回のみ(ブラウザ本体を取得)
npm test                       # tests/regression.js を実行
```

- ~~**攻略本がゲーム本体から自動生成されていない**~~ **対応済み(2026-09-28)**: `guide_template.html`(手書きの文章・レイアウト)+`scripts/build_guide.js`(データ抽出・埋め込み)の構成に変更。`node scripts/build_guide.js`を実行するだけで、`audio_data.js`/`game.js`の実データから`complete_guide.html`と`secretguide_data.js`が再生成されるようになった。今後は数値変更時にビルドを再実行すれば自動的に同期される(公開アーティファクトへの再publishは引き続き手動)。
- **実績拡張(50→100)で古参プレイヤーの実績通知が雪崩れる可能性**: 新しい50種の多くは「これまでの累計」を見る条件のため、長く遊んでいるプレイヤーは更新後の最初の勝利で複数個同時解除されうる。通知は1件1.8秒の順次表示のため、オートスピン中などに通知が詰まり続ける体験になりうる(実害は演出面のみ)。
- **進行状況がlocalStorageのみで、バックアップ/エクスポート機能が無い**: キャッシュクリアや端末変更で実績・所持金が全て消える。積み上げた実績が多いプレイヤーほど失うものが大きい。
- **後のテーマを解禁すると前のテーマがほぼ遊ばれなくなる**: 還元率が段階的に跳ね上がる設計の裏返しで、ミミック/スライム/ゾンビは終盤ではテーマ固有実績目的以外で遊ぶ理由が薄れる。
- **数字のインフレが早い**: ゼニス到達後は所持金が兆単位に到達しうる規模で、数字自体の実感・達成感が薄まっていく可能性(「非現実的な数字でいい」という本人方針は把握済み、その上での留意点)。
- **terrariajpサーバー向けなのに、プレイヤー間の繋がり要素が皆無**: ランキング・実績の見せ合い・共有ジャックポットなど、コミュニティ向けらしい体験が今のところ無い。
- ~~**リポジトリに自動テストが一切コミットされていない**~~ **対応済み(2026-09-28)**: `tests/regression.js`(+`package.json`)としてリポジトリにコミット。`npm install`→`npm test`で、UIの全モーダル・確変/瓶の延長・ゼニスの払い出し額・メダル上限・攻略本の遅延読み込み・セーブのエクスポート/インポートなど24項目を自動検証できる(手順は下記「テストの実行方法」参照)。
- ~~**ディフェンダーメダルがTerraria本編のアイテムスタック上限(9999枚)に従っていない**~~ **対応済み(2026-09-28)**: `checkPlatinumAutoConvert()`に9999枚上限を実装。超過分の白金貨は変換されず残る。
- ~~**進行状況がlocalStorageのみで、バックアップ/エクスポート機能が無い**~~ **対応済み(2026-09-28)**: ガイド内に「セーブデータのバックアップ」欄を追加。JSONファイルとして書き出し・読み込みができる。
- ~~**サーバー向けなのにプレイヤー間の繋がり要素が皆無**~~ **一部対応(2026-09-28)**: バックエンドを持たない静的サイトという制約の中でできる範囲として、実績一覧(看板)の📤ボタンから実績数・到達テーマ・所持金などをまとめたカード画像を生成しDiscordに貼れる機能を追加。ランキング等サーバー全体で同期する機能は引き続き無し(実装するにはバックエンド新設が必要)。
- ~~**UIの情報密度が高く、初見の導線がやや弱い可能性**~~ **対応済み(2026-09-28)**: 初回訪問(セーブデータが存在しない状態)時のみ、自動でガイドを一度だけ開くようにした。既存プレイヤーのセーブには影響しない。
- **UIの情報密度が高く、初見の導線がやや弱い可能性**: 小さい画面にアイコン・数字が密集しており、ガイドを能動的に開かないと何をすべきか分かりにくいかもしれない。
- (**参考・対応不要と判断済み**)RTPが常に100%を大幅に超えるため「損をする緊張感」がほぼ無い→本人からドーパミン重視でスリル不要と明言済み、対応しない方針で確定。
