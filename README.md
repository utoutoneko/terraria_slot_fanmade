# MIMIC SLOTS — Claude Code 引き継ぎメモ

## ファイル構成
- `CLAUDE.md` — Claude Codeが自動で読む標準指示(素材の自律取得・進め方のルール)。**最優先で読まれる想定**
- `PROJECT_BRIEF.md` — これまでの全チャットの経緯を漏れなくまとめた完全版ブリーフィング
- `index.html` — ページ骨格(構造のみ)
- `style.css` — 全スタイル
- `sprites_data.js` — 画像素材(base64埋め込み、`const SPR = {...}`)
- `audio_data.js` — 音源(base64埋め込み、`const AUDIO_SRC = {...}`)
- `game.js` — ゲームロジック本体

ローカルでは `index.html` をブラウザで直接開くか、簡易サーバー(`python3 -m http.server`)経由で開いてください。file://直接開きでも動作確認済みです。

## 現状(全部実装・実機検証済み)
- 3×3リール、8ライン判定(横3・縦3・斜め2)、ミミック7種の配当システム
- ミステリーポット、フリースピン、連勝ストリーク倍率、瓶(2倍配当バフ)、マナ(流れ星収集→ミミック除外効果)
- 実績19種、発掘ミニゲーム、8枠インベントリ列、ガイド/看板/机/金貨山の各UI導線
- 昼夜サイクル(太陽・月、地平線の下に正しく隠れる)、装飾一式(木・キノコ・ひまわり・机・椅子)
- ジャングルミミック演出は緑パーティクル/オーバーレイ/ツタを全廃し、木が画面上から降る演出に統一済み
